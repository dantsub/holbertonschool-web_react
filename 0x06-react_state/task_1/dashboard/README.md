# React Dashboard

React 19 application built with [Vite](https://vitejs.dev/) and tested with [Vitest](https://vitest.dev/) and [@testing-library/react](https://testing-library.com/react).

## Available Scripts

In the project directory, you can run:

### `pnpm start`

Runs the app in development mode with Hot Module Replacement (HMR).
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `pnpm test`

Runs the test suite with Vitest in watch mode using a jsdom environment.
Tests use @testing-library/react and @testing-library/jest-dom.

### `pnpm build`

Builds the app for production to the `dist` folder.
The bundle is optimized for production.

### `pnpm preview`

Serves the production build locally to preview it before deploying.
